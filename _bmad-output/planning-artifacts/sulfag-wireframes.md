# Sulfag Products Limited - Website Wireframes

**Design Style:** Organic Modern + Clean Corporate Hybrid  
**Created:** 2026-01-11  
**Author:** Sally (UX Designer) + Saisharan.v

---

## Design Philosophy

### The Hybrid Approach

```
ORGANIC MODERN (60%)          +          CLEAN CORPORATE (40%)
─────────────────────                    ─────────────────────
• Warm earth tones                       • Grid-based layouts
• Agricultural imagery                   • Clear data tables
• Curved elements (buttons)              • Structured navigation
• Generous whitespace                    • Professional typography
• Subtle nature textures                 • Formal sections
• Heritage storytelling                  • Consistent spacing
```

### Brand Colors Applied

| Element | Color | Hex |
|---------|-------|-----|
| Headers, Nav, Table Headers | Dark Olive | `#48501e` |
| Hover states, Icons, Accents | Sage Green | `#8E9969` |
| Page backgrounds, Alt rows | Light Cream | `#e7e5d7` |
| CTA Buttons, Active states | Earth Brown | `#846639` |
| Borders, Dividers | Warm Beige | `#c2b19c` |
| Clean sections | White | `#FFFFFF` |
| Body text | Dark Grey | `#333333` |

### Typography

| Usage | Font | Size |
|-------|------|------|
| H1 Headlines | TT Chocolates Bold | 48-56px |
| H2 Section Titles | TT Chocolates SemiBold | 32-40px |
| H3 Subsections | TT Chocolates Medium | 24-28px |
| Body Text | Proxima Nova Regular | 16-18px |
| Button Text | Proxima Nova SemiBold | 14-16px |
| Table Text | Proxima Nova Regular | 14-15px |
| Small/Caption | Proxima Nova Regular | 12-14px |

## Parallax Section Specification (Homepage CTA Section)

### What is Parallax?
The background image stays **fixed** while the page content scrolls over it, creating an optical illusion of depth - similar to Anglo Gulf's "Services" section.

### How Parallax Works (Technical):

```
SCROLLING BEHAVIOR:

┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
│ ░░░░░░░░░░░░░░░ │        │                 │        │                 │
│ ░░ TOP OF ░░░░░ │        │ ░░░░░░░░░░░░░░░ │        │                 │
│ ░░ IMAGE ░░░░░░ │   ──►  │ ░░ MIDDLE ░░░░░ │   ──►  │ ░░░░░░░░░░░░░░░ │
│ ░░░░░░░░░░░░░░░ │        │ ░░ OF IMAGE ░░░ │        │ ░░ BOTTOM ░░░░░ │
│ ┌─────────────┐ │        │ ░░░░░░░░░░░░░░░ │        │ ░░ OF IMAGE ░░░ │
│ │ CONTENT BOX │ │        │ ┌─────────────┐ │        │ ░░░░░░░░░░░░░░░ │
│ │ moves up    │ │        │ │ CONTENT BOX │ │        │ ┌─────────────┐ │
│ └─────────────┘ │        │ │ is here now │ │        │ │ CONTENT BOX │ │
│                 │        │ └─────────────┘ │        │ │ is here now │ │
│  (hidden)       │        │                 │        │ └─────────────┘ │
└─────────────────┘        └─────────────────┘        └─────────────────┘

START                      MIDDLE                     END
(top of image visible)     (middle visible)          (bottom visible)
```

The background image is FIXED in place. The section "window" moves over it as you scroll!

### CSS Implementation:

```css
.parallax-cta-section {
  /* Section dimensions */
  min-height: 450px;
  display: flex;
  align-items: center;
  justify-content: center;
  position: relative;
  
  /* Parallax background */
  background-image: url('parallax-farm-field.jpg');
  background-attachment: fixed;    /* ← THE MAGIC */
  background-size: cover;
  background-position: center center;
  background-repeat: no-repeat;
}

/* Dark overlay for text readability */
.parallax-cta-section::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background-color: rgba(72, 80, 30, 0.65);  /* #48501e at 65% */
  z-index: 1;
}

/* Content above overlay */
.parallax-cta-section .content {
  position: relative;
  z-index: 2;
  text-align: center;
  color: white;
}
```

### ⚠️ IMAGE REQUIREMENTS FOR PARALLAX:

| Specification | Requirement | Why |
|--------------|-------------|-----|
| **Minimum Height** | **1500px - 2000px** | Must be taller than viewport for scroll effect |
| **Minimum Width** | **1920px** | Full HD screens |
| **Ideal Dimensions** | **1920 x 1400** or **2560 x 1700** | Covers most displays |
| **Aspect Ratio** | ~16:10 or 3:2 | Landscape orientation |
| **File Format** | JPG or WebP | Compressed for fast loading |
| **File Size** | **200-400KB** (optimized) | Performance |
| **Content** | Agricultural field, crops, farmland | Must work with overlay |

### 📸 Recommended Image Types for Parallax:

1. **Green crop field with rows** (like Anglo Gulf's tea plantation)
2. **Indian farmland at golden hour**
3. **Rice paddy or wheat field panorama**
4. **Sugarcane or cotton field**
5. **Aerial view of agricultural land**

### What to Ask Client:

```
"For the website, we need a HIGH-RESOLUTION agricultural image 
for the parallax effect (like Anglo Gulf's Services section).

Requirements:
- Size: At least 1920 x 1500 pixels
- Content: Farmland, crop field, or agricultural scene
- Format: JPG
- Quality: High resolution, not blurry

Do you have photos of Indian farmland, or should we source 
a professional stock image?"
```

### Mobile Fallback:

⚠️ **Note:** `background-attachment: fixed` doesn't work well on mobile devices. For mobile, we disable parallax and use a static background:

```css
@media (max-width: 768px) {
  .parallax-cta-section {
    background-attachment: scroll;  /* Disable parallax on mobile */
    background-position: center;
  }
}
```
