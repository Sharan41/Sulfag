## 📝 Step-by-Step Instructions

### 1. Go to Contentful
- Visit: https://app.contentful.com/spaces/kvec8c4ex2a6/entries
- Click **"Add entry"** (top right)
- Select **"Product"**

### 2. Fill in the Fields

Copy and paste these exact values:

| Field | Value |
|-------|-------|
| **Product Name** | `ACEPHATE 75% SP` |
| **Brand** | `SULFAG` |
| **Packing** | `10X1 KG; 20X500 GM` |
| **Crops** | `Cotton, Rice, Sugarcane` |
| **Target Pests** | `Jassid, Bollworm` |
| **Category** | `insecticides` |
| **ID** | `50` |

### 3. Important Notes

- **Category** must be exactly one of:
  - `insecticides`
  - `fungicides`
  - `herbicides`
  - `specialty`
  
- **ID** must be a unique number (check existing products to avoid duplicates)

- **Packing** can have multiple options separated by semicolons (`;`)

- **Crops** and **Target Pests** can have multiple items separated by commas (`,`)

### 4. Publish

- Click **"Publish"** button (top right, green button)
- ✅ Product will appear on your website instantly!
