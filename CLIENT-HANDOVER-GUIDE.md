## ✏️ Field Guidelines

### Product Name
- Use the full product name as it appears on packaging
- Example: `ACEPHATE 75% SP`

### Brand
- Your brand name or manufacturer name
- Example: `SULFAG`

### Packing
- Describe packaging sizes and quantities
- Use semicolons to separate multiple options
- Example: `10X1 KG; 20X500 GM`

### Crops
- List all crops this product can be used on
- Separate multiple crops with commas
- Example: `Cotton, Rice, Sugarcane`

### Target Pests
- List pests/diseases/weeds this product targets
- Separate multiple targets with commas
- Example: `Jassid, Bollworm`

### Category
- Must be exactly one of these:
  - `insecticides`
  - `fungicides`
  - `herbicides`
  - `specialty`
- Type it exactly as shown (case-sensitive)

### ID
- Unique number for each product
- Use numbers only (1, 2, 3, etc.)
- Don't duplicate existing IDs

## 🚨 Troubleshooting

### Product Not Appearing on Website?

**Check:**
1. ✅ Did you click "Publish" (not just "Save")?
2. ✅ Is the product published? (Check for green "Published" badge)
3. ✅ Refresh your website (Ctrl+F5 or Cmd+Shift+R)
4. ✅ Check browser console for errors (F12)

### Can't Edit a Product?

**Check:**
1. ✅ Are you logged into Contentful?
2. ✅ Do you have edit permissions?
3. ✅ Is the product locked by another user?

### Changes Not Showing?

**Solution:**
- Wait 10-30 seconds (Contentful CDN cache)
- Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
- Clear browser cache

### Wrong Category Count?

**Solution:**
- Category counts update automatically
- Make sure products have correct category field
- Refresh the page
